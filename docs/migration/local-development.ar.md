# تشغيل سُحُب محليًا وإنشاء المدير الأول

المسار `/root/So7ob/web` مستقل عن Website. يعتمد على Node 24.21.0 وnpm 10.8.2 وMariaDB 10.11.18. لا توجد كلمة مرور مدير افتراضية ولا حساب مخفي.

انسخ `.env.example` إلى `.env` غير متتبع، واضبط قاعدة MariaDB محلية مستقلة وصلاحيات مستخدمها. اضبط `NODE_ENV=development` و`SITE_URL` و`WEB_ORIGIN` على عنوان المتصفح نفسه. عند استخدام `http://localhost:3108` استخدمه لكلا المتغيرين؛ وعند استخدام `http://127.0.0.1:3108` استخدم ذلك لكليهما. أنشئ `AUTH_SECRET` و`OUTBOX_KEY` عشوائيين مستقلين؛ لا تستخدم قيم `replace-*`. لا توجّه الاتصال إلى Website.

```sh
cd /root/So7ob/web
npm ci
npm run db:migrate
```

الأمر السابق ينشئ المخطط فقط. إذا كانت قاعدة **التطوير الجديدة فارغة**، استبدل `so7ob` باسم `DATABASE_NAME` الفعلي:

```sh
npm run site:init -- --database=so7ob --confirm-empty
```

ينشئ الصفحات العامة الأصلية السبع بالعربية والإنجليزية، والقوائم وإعدادات الموقع. يرفض وجود أي صفحات أو إصدارات أو قوائم أو إعدادات؛ لا يحذف بيانات ولا يكتب فوق محتوى محرر. ليس أداة ترحيل لبيانات الإنتاج. إذا كنت قد استوردت بيانات معزولة، تخطَّ هذه الخطوة واستخدم أدوات المطابقة في دليل الترحيل.

لإنشاء المدير الأول محليًا، ضع بريدك الحقيقي بدل المثال:

```sh
npm run admin:create -- --database=so7ob --email=you@example.com --name="مدير النظام"
```

يطبع الأمر كلمة مرور عشوائية مرة واحدة في الطرفية. احفظها في مدير كلمات مرور، وسجّل الدخول بها على `http://localhost:3108/ar/auth/login` ثم افتح `http://localhost:3108/ar/admin`. الحساب نشط ومتحقق محليًا وصلاحيته `super_admin`، وكلمة مروره محفوظة بتجزئة bcrypt، لا كنص صريح. لا تُرسَل رسالة بريد لتجهيز هذا الحساب المحلي.

إذا أردت اختيار كلمة مرورك، استخدم `--password-from-stdin` وأدخلها من أداة آمنة عبر stdin؛ لا تضعها في وسيطات الأمر أو Git أو سجل الطرفية. مثال Bash لإدخال مخفي:

```sh
read -rsp 'كلمة المرور: ' so7ob_admin_password
printf '\n'
printf '%s' "$so7ob_admin_password" | npm run admin:create -- --database=so7ob --email=you@example.com --name="مدير النظام" --password-from-stdin
unset so7ob_admin_password
```

يرفض الأمر بيئة الإنتاج أو اتصالًا غير محلي أو اسم قاعدة مختلفًا، ويرفض وجود مدير سابق حتى لو كان موقوفًا، ويرفض بريد حساب قائم. عند وجود مدير استخدم واجهة المستخدمين والدعوات داخل لوحة الإدارة؛ لا تعِد تشغيل التهيئة ولا تعدّل كلمات المرور في SQL.

```sh
npm run build
npm run dev
```

المنفذ الافتراضي في المثال `3108`. افتح `/ar` أو `/en` للموقع العام. زيارة `/ar/admin` دون جلسة صحيحة تحوّلك إلى الدخول؛ حساب العميل يُحوّل إلى `/ar/account`.

ظهور 404 على `/ar` بعد `db:migrate` قد يعني غياب المحتوى المنشور. افحص اتصال `.env` وبيانات النسخة المستوردة؛ لا تعالج الموقع القائم بمسح القاعدة أو إعادة البذر. إعادة تهيئة بيانات الإنتاج والنشر والتحويل إجراءات منفصلة غير منفذة بهذا الدليل.
