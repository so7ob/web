# دقة أخطاء نماذج المصادقة — #68

Issue: https://github.com/so7ob/web/issues/68. فرع `fix/68-auth-error-state` من حزمة #65 عند `7e9470a`، يعتمد على PR #67 ثم #66 ثم #64، وقاعدة PR develop. التطوير في `/root/So7ob/web` فقط.

## الأدلة والإصلاح

اختبار متصفح اصطناعي قبل الإصلاح فشل في النماذج الأربعة على البناء `7e9470a`: forgot عرض قبولًا رغم 401؛ register لم يعرض التصنيف/التتبع عند 500؛ reset وinvite وصفا 500 بأنه رابط غير صالح. لا طلب على حساب حقيقي ولا إرسال بريد.

| العملية | التصنيف | السلوك الحالي | اختبار القبول |
|---|---|---|---|
| forgot-password | عيب مؤكد: نجاح وهمي | النجاح يحتاج HTTP ناجحًا وok:true؛ الرد المحايد لا يكشف وجود الحساب | 401/403/429/500 والشبكة وHTML بدل JSON ثم قبول 200 |
| reset-password | عيب مؤكد: سبب غير مثبت | invalid_token وحده يعرض الرابط غير الصالح؛ تبقى كلمة المرور والتأكيد عند الفشل | 500 والشبكة والرد المعطوب، ثم invalid_token |
| invite | عيب مؤكد: سبب غير مثبت | invalid_token وemail_taken الصريحان فقط يفسران السبب، مع بقاء الاسم وكلمة المرور | الحالات السابقة وأخطاء الحقول القائمة |
| register | قصور تشخيصي | أخطاء الحقول كما هي؛ الفشل الآخر يحمل التصنيف ومرجع الخادم/مرجعًا محليًا | فشل الخادم والنقل والرد المعطوب، ثم email_invalid بجوار الحقل |

حراس فورية تمنع ضغطتين أثناء الكتابة؛ لا إعادة إرسال تلقائية أو مسح للمدخلات. لا تغيير للمصادقة أو bcrypt أو شروط كلمات المرور أو الرموز أو HTTP أو schema. الرسائل مأخوذة من الرموز والحالات، لا من رسالة مزود خام.

أظهر اختبار axe مع لقطة شاشة أن رأس الصفحة الثابت كان يحجب جزءًا من زر نسخ المرجع في نموذج الدعوة العربي على عرض 375 بعد التركيز على زر الإرسال. أصبح ErrorFeedback يتيح focusOnError للنماذج: ينقل التركيز إلى ملخص الخطأ ويظهره كاملًا، دون إخفاء عناصر أو تغيير baseline. بقي الخيار معطلًا افتراضيًا لبقية الرحلات كي لا ينتزع التركيز من مسودة قيد التحرير.

## نتائج الجولة المركزة وحدودها

أخفقت الحالات الأربع الإنجليزية قبل الإصلاح. الجولة الأولى بعد الإصلاح: 15/16؛ الفشل الوحيد كشف حجب زر النسخ المذكور. بعد إصلاح التركيز نجحت الحالات الـ16 بالعربية/الإنجليزية وRTL/LTR وعرضَي 375 و1280 ولوحة المفاتيح وaxe، على شجرة العمل فوق `7e9470a` قبل الالتزام بهذه الحزمة. هذه أرقام الجولة المركزة وليست ادعاء نجاح بوابات SHA لاحق. نتائج البوابات الكاملة وSHA الفعلي محفوظة في PR وGitHub Actions.
