# إصلاح صحة التدقيق عند اختلاف collation — #72

[Issue #72](https://github.com/so7ob/web/issues/72)؛ الفرع `fix/72-audit-health-collation` من `develop` عند `e779ace0bfd49701969c2fb330b24a17dce6f24c`. نسخة الإصلاح: `d978938b431456ca10297ef24937f6ebbcaef6b6`.

## السبب المثبت

فحص قراءة فقط لقاعدة الخدمة المحلية على 3108 أعاد `ER_CANT_AGGREGATE_2COLLATIONS` / 1267 في الاستعلامين نفسيهما المشار إليهما بالصور: `AuditOperations.probe` و`AuditOperations.health`. عمود `AuditLog.id` يستخدم `utf8mb4_nopad_bin`، و`AuditWork.eventId` و`AuditCaseEvent.eventId` يستخدمان `utf8mb4_bin`. تعريف CREATE TABLE IF NOT EXISTS في migration الحالية لا يبدل جدولًا موجودًا. الاختبارات السابقة استخدمت جداول متطابقة في collation، ولذلك لم تغطِّ هذا التكوين. لا نفترض كيف أو متى نشأ الاختلاف.

## الإصلاح

أصبحت مقارنة معرف الحدث في الربط صريحة باستخدام `COLLATE utf8mb4_nopad_bin` على طرف جدول المتابعة. يطابق ذلك دلالة المفتاح الأساسي للدليل: الأحرف والمسافة النهائية لها معنى. يشمل الإصلاح قراءة الصحة والفحص الدوري واختيار مهمة العامل وفحص منع الحذف في الاحتفاظ. لا يحوّل أعمدة قاعدة المستخدم ولا يعدّل الأدلة ولا يضيف migration أو يمنح صلاحيات.

تحدد COLLATE الصريحة أولوية المقارنة عند تعارض قواعد الأعمدة، وفق [عقد MariaDB](https://mariadb.com/docs/server/reference/sql-functions/secondary-functions/information-functions/coercibility). فحص EXPLAIN لاختيار المهمة يستخدم `audit_work_due` ثم `AuditLog.PRIMARY` بنمط `eq_ref` وصف واحد؛ لم يتحول بحث الدليل إلى مسح كامل. استعلام الاحتفاظ يظل عمل صيانة يحتاج مسح الأدلة القديمة وروابط المنع، وليس ادعاء أداء ثابت لكل حجم.

## الاختبارات والأدلة

- اختبار MariaDB جديد يغيّر collation داخل قاعدة اختبار معزولة فقط ويعيده في finally. فشل على الكود السابق بالخطأ 1267 نفسه ونجح بعد الإصلاح.
- يتحقق من حفظ الفحص، قراءة الصحة، رفض غير المخول، معالجة المهمة الصحيحة، وعدم معالجة معرف مختلف بالحالة أو المسافة النهائية. يتأكد أن dry-run لا يحذف وأن الصيانة تحفظ الدليل المحمي دون تغيير صفه ولا تمنح منع حذف بسبب معرف مشابه.
- اختبار متصفح جديد على AR/EN و375/1280: HTTP 200 لصحة التدقيق، عرض الفحص والسياسة، تشغيل dry-run بلوحة المفاتيح، عدم تمدد الصفحة أفقيًا وaxe. الصور بيانات اصطناعية من خادم فعلي بالنسخة المذكورة، وليست صور حساب المستخدم.
- الاختبار المخصص الأول أُلغي بعد تداخل ملف fixture بين تشغيلين في مساحة بناء واحدة. أعيد في مساحة مستقلة، دون تغيير assertions، ونجحت الحالات الأربع. الحزمة الشاملة نُفذت في مساحة بناء وقاعدة منفصلتين ونجحت حالاتها الـ240.
