## الاستثناءات المحدودة لحماية البيانات

المصدر يفصل التحقق من استخدام الملف عن حذفه؛ قد يضيف حفظ متزامن مرجعًا بين العمليتين. الهدف يربط حذف الوسائط وكتابة الصفحات والقوالب بقفل MariaDB `cms-pages` نفسه. إذا سبق الحفظُ الحذفَ يُرفض الحذف؛ وإذا سبق الحذفُ الحفظَ تُرفض الإشارة المفقودة بـ409 و`media_not_found`. تشمل الحماية عناوين `/api/media/` و`/api/v1/media/` وحدود المعرّف الدقيقة.

إضافة إلى عمود OG القديم، تُفحص إعدادات المسودة والمنشور المنفصلة حتى لا يسمح حذف ملف ما زالت تستخدمه إحدى النسختين. النسخ التاريخية وحدها لا تمنع الحذف، بما يوافق نطاق المصدر، لكن استعادتها إلى مسودة تُرفض إذا أشارت إلى ملف محذوف؛ يُحفظ الإصدار التاريخي ولا تتغير المسودة أو النسخ الاحتياطية عند الرفض. لا إصلاح صامت لمحتوى قائم ولا حذف بيانات قديمة.

بناء فهرس الاستخدام يعتمد على استعلامي الصفحات والقوالب واستعلام الوسائط الموحد، دون استعلام لكل صورة. اختبار النمو يثبت ثبات عدد SELECT، لكنه لا يثبت ميزانية الزمن/الذاكرة لقاعدة كبيرة: الفهرس يقرأ مستندات CMS ضمن القفل، وتظل قياسات الحمل النهائية مطلوبة.

نجحت المجموعة الكاملة للوحدة والتكامل: 360 اختبارًا في 36 ملفًا على MariaDB فعلية. نجحت الرحلات المركزة الأربع وlint وtypecheck وbuild وtest:infra. نجحت المجموعة الكاملة للمتصفح: 100/100 دون retries. المقارنة البصرية للمكتبة نجحت 4/4: اختلاف بكسلات RGB صفر دون أقنعة، ولا مخالفات axe أو أخطاء Console/Network في المرجع والهدف. الصور في `evidence/media-library/parity/`؛ هذه نتيجة آلية مع فحص صور بواسطة الوكيل، وليست اعتماد المراجعة البشرية المطلوبة.

السجلات المحلية في `.migration/media-library/`؛ الملخصات المتتبعة في `evidence/media-library/` عند اكتمال تشغيلها. المحاولات الفاشلة محفوظة: إعداد fixture أولي استعمل NULL لحقل إعدادات غير قابل لـNULL، ثم صُحّح إلى `{}`؛ نمط تحكم موروث رفضه ESLint استُبدل بتطبيع مكافئ دون تعطيل القاعدة؛ استدلال نوع استجابة القائمة كشف نوعًا داخليًا أثناء بناء declarations فاستُبدل بعقد DTO عام صريح. حالة الاستعادة احتاجت fixture غير فارغ بنوع كتلة صحيح، ومقارنة المحتوى المخزن بعد تطبيع المحرر بدل JSON المدخل الخام؛ لم تُغيّر حماية المنتج أو شروط القبول بسبب ذلك.

## النسب وحدود التسليم

واجهة `src/components/admin/media/media-client.tsx` وأنواع الوسائط مستمدة من Website عند SHA أعلاه، و`src/lib/media-usage.ts` واختباراته أساس الدوال المشتركة. خدمات Prisma أُعيد تنفيذها داخل Nest/TypeORM ولم تُستورد إلى التشغيل. سجلات الاستيراد القديمة والترخيص محفوظة؛ خريطة بصمات هذا الجزء ضمن manifest التحديث.
