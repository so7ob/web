## التحقق والحدود

فحوص [PR #95](https://github.com/so7ob/web/pull/95) على `667be814d64fd7e8c11f84dd7dfa442087874ad5` نجحت: 958 اختبار وحدة/تكامل و290 اختبار متصفح وجميع البوابات الحالية. تم التحقق من مطابقة شجرة هذا المصدر لقاعدة التحضير `513eef7`؛ اختلاف SHA يبقى صريحًا. هذه النتيجة مرجع المنتج السابق، وليست بديلًا عن CI التحضير والترقية.

التحضير يتحقق من تطابق نسخ package/lock، ومن الروابط المحلية المتغيرة، ومن أن فرق القفل لا يغير إصدارات الاعتماديات أو workspaces. تبقى جميع الفحوص المطلوبة مفعلة في CI: lint وtypecheck وtest وbuild وtest:independence وtest:e2e وtest:infra وdiff check، مع الترحيلات والاستعادة والعامل والملفات والمصادقة والـwebhook وCMS. البيانات والأصول المستخدمة في الاختبار اصطناعية فقط.

الفحص المحلي قبل commit التحضير نجح: تطابق النسخة `1.3.0` في package والقفل، وعدم أي تغيير آخر في قفل الاعتماديات/workspaces، وصحة **106** روابط محلية في الوثائق المتغيرة. أوامر lint وtypecheck وbuild وtest:independence وtest:infra و`git diff --check` خرجت بـ0. اختبارات الوحدة والمتصفح الكاملة تُنفذ مجددًا في CI التحضير والترقية؛ لا تُعرض هنا كنجاح محلي جديد أو نتيجة مكتملة قبل صدورها.

لا يثبت إصدار GitHub تفعيل SMTP خارجي أو فقد مضيف/تعافٍ مستقل أو جاهزية بيانات إنتاج. لا تعديل للإعدادات الفعلية أو أسرار المستخدم أو `.env` أو قواعد البيانات التشغيلية. لا تُرفع `.migration` أو build outputs أو بيانات خاصة كأصول إصدار. التراجع عبر PR جديد؛ احتفظ بالبيانات الحديثة وتاريخ سير العمل وحالات بيانات الدخول بدل إسقاطها أو استعادة بيانات قديمة.
