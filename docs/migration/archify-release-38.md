# تسليم Archify والإصدار — #38

## النطاق والتفويض

طلب المستخدم حفظ المهارات ومخرجات Archify في فرع ورفعها ودمجها إلى develop ثم main وإنشاء إصدار جديد وتحسين README بالصور. هذا التفويض يجيز الدمج والإصدار لهذه المهمة؛ لا يشمل نشر تطبيق أو نقل بيانات إنتاج. فرع العمل docs/38-archify-release؛ نقطة البداية develop عند e84fe1b3c3f6b2fd9bf2c79c0a08e53458e5dae3، وmain عند 8f69f6fef0982a526ed9f8e3bf7b7919bf4c485a. تم التحقق من origin وهوية so7ob/web قبل الكتابة البعيدة.

## المحتوى

حفظ حزمة Archify مع رخصتها وإشعاراتها وskills-lock، ومخرجات البنية والتسلسل وسير العمل ودورة الحياة. المهارات الأخرى كانت متتبعة بالفعل وتدخل الإصدار عبر develop. نماذج الوكيل توضيحية فقط. README يتضمن صورًا من المخرجات وروابط أدلة وخريطة الحزم، ويصحح الحالة التاريخية وفق final-code-parity.md وPR #37. إصدار الحزمة الجذرية 1.1.0، دون تغيير اعتمادات التشغيل.

حُفظت التقارير السابقة بوصفها سجلات لوقت إنشائها؛ عبارات «لم يُرفع» و«المهارة غير متتبعة» تصف ذلك الوقت، ويحل سجل التسليم هذا وPR محلها لحالة النشر. لم تُعدل snapshots أو مصادر التطبيق المنسوبة إلى commit أقدم.

## ضبط المخرجات

كشف diff check مسافات نهائية في قوالب الحزمة وHTML المولد. عولجت دون تغيير المعنى أو تعطيل قواعد الفحص. [سجل بصمات التطبيع](evidence/archify-release-38/normalization.json) يسجل الملفات الأصلية والمطبعة؛ computedHash في skills-lock يصف المصدر المستورد قبل هذا التطبيع المحلي، وليس بصمة شجرة معدلة. أُعيد finalize للمخرجات الستة النهائية باستخدام القالب المطبّع؛ الإيصالات الجديدة في release-review بجوار كل HTML هي المرجع المنشور. الإيصالات واللقطات السابقة تاريخية؛ التطبيع لا يغير الرسم المرئي. request.html المجمع القديم محاولة مستبدلة وليس تسليمًا نهائيًا، وإيصاله السابق يصف بايتات ما قبل التطبيع.

استُبعدت caches وملفات tmp وسجلات الأوامر من Git؛ بقيت ملخصات النتائج والبصمات. لم تُرفع .env أو بيانات حقيقية أو ملفات عملاء.

## التحقق

[نتائج أوامر المستودع وبصمات السجلات](evidence/archify-release-38/checks.json): lint وtypecheck وbuild وinfra نجحت. npm test نجح في 687 اختبارًا ضمن 24 suite، وفشل تحميل 17 suite لغياب إعداد MariaDB اختبار معزولة. E2E رفض البدء دون قاعدة اختبار صريحة. هذه قيود تشغيل محلي وليست نجاحًا للاختبارات الكاملة؛ PR CI يهيئ MariaDB المعزولة ويعيد التحقق قبل الدمج. تغيير رقم النسخة فقط جاء بعد هذه الأوامر ويغطيه CI للرأس المرفوع.

راجعت بصريًا صور README، وهي صور مخططات وليست صور واجهة المنتج. فحوص العارض السابقة بعرضي 375/1280 وLTR/RTL المحاكى موثقة؛ أربع مخالفات axe في قالب العارض باقية، ولم يعدّل هذا التغيير واجهة التطبيق. نتائج finalize الجديدة مسجلة في finalize-results.json. diff check يُعاد على الملفات المرحّلة قبل الالتزام.

## التراجع وحدود الإصدار

التراجع عن إضافة التوثيق والمهارة عبر revert لالتزامها؛ التراجع عن تغييرات التطبيق السابقة يحتاج مراجعة مستقلة. لا حذف لتاريخ المصدر أو للإصدارات. الإصدار يجمع develop منذ v1.0.0، ولا يثبت نشرًا إنتاجيًا. روابط PR وحالة CI والدمج والإصدار النهائية تُسجل على GitHub بعد تحققها الفعلي.
