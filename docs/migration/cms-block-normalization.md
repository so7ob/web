## السلوك المنقول

- فحص نوع الكتلة بملكية مفتاح مباشرة؛ `constructor` و`hasOwnProperty` و`__proto__` و`toString` تعيد رفضًا مضبوطًا، ولا تستدعي `safeParse` على خصائص موروثة.
- نتيجة التحقق هي بيانات Zod المطَبّعة، مع حذف الخصائص غير المعروفة وتطبيق القيم الافتراضية كما في المصدر الجديد.
- الخدمة تحفظ النتيجة المطَبّعة في إنشاء المسودة وتعديلها ونشرها وإصداراتها واستعادتها. إعادة التحقق عند النشر والاستعادة تحمي أيضًا من JSON تاريخي غير مطَبّع دون تعديل الأرشيف الأصلي تلقائيًا.
- يبقى منع التسريب، والصلاحيات، وCSRF، وحماية الصفحة الرئيسية، وقفل التزامن الدقيق، ورفض الحفظ المتعارض كما كانت.

تغير اختبار «JSON الخام مطابق حرفيًا» إلى مقارنة البيانات المطَبّعة لجميع الأنواع الـ27 مقصود: المصدر المحدث يسقط المفاتيح غير المعروفة ولا يحفظ التنسيق الحرفي للـJSON. لا تتغير حدود قبول الأداء أو الصور أو axe.
