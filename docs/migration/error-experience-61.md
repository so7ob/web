## سلوك الاسترداد

المساعدان القديمان للإدارة والحساب يحتفظان بواجهات الاستدعاء مع استخدام نقل مشترك. لا حذف للقيم false/0/السلسلة الفارغة/null. الكتابة محاولة واحدة دون retry تلقائي. خطأ النقل بعد الكتابة يوضح أن الحفظ قد يكون تم، ويدعو إلى جلب البيانات قبل المحاولة. نتيجة الحفظ المؤكدة منفصلة عن فشل إعادة الجلب؛ تبقى المسودات عند فشل الكتابة، ولا يعاد إرسالها تلقائيًا. الأخطاء المحلية تحمل local- ولا تدعي requestId من الخادم.

ErrorFeedback يدعم العربية/الإنجليزية وRTL/LTR، العملية والسبب المصنف والإجراء ونسخ المرجع، وFieldError يربط رسالة التحقق بالحقل دون تغيير اسمه المقروء. الواجهة لا تعرض message الخام ولا قيم السجل المحذوفة. الملف الشخصي والأمان يحافظان على أخطاء الحقول القائمة ويعرضان الأعطال الأخرى قرب النموذج. مساعدات الإدارة القديمة تحصل أيضًا على التصنيف والمرجع دون تغيير توقيعها.

أخطاء المتصفح غير المعالجة تُسجل محليًا بمخرج allowlist (المكوّن/الوقت/الحدث/معرّف محلي/SHA البناء) مع منع تكرار التنبيه 30 ثانية. لا توجد نقطة استقبال تقارير متصفح ولا إرسال خارجي، ولا جمع DOM أو لقطات أو نماذج. خطأ React الذي يُسقط الشجرة قد يفقد حالتها؛ لا يُدّعى إمكان استعادة مدخلات مكوّن انهار. فشل bootstrap يبقي DOM الموجود ويعرض تحذير النسخ قبل إعادة التحميل.

## التحقق والتراجع

اختبارات مركزة سابقة على شجرة العمل: 9 نقل، و28/32 متصفح في الجولة الأولى؛ أصلح محدد عنوان مكرر وربط label برسالة التحقق ثم نجحت اختبارات الشاشة الثمانية كاملة دون استثناء axe. النتيجة النهائية لكل SHA في PR وCI؛ هذه أرقام جولات مركزة وليست ادعاء نجاح بوابات الرأس النهائي.

البيئة الاصطناعية: Node 24.21.0، npm 10.8.2، MariaDB 10.11.18 على منفذ معزول، Chromium بواجهتي 375 و1280، العربية/الإنجليزية، لوحة مفاتيح وaxe. لا تغيير baseline ولا إخفاء عناصر. نجاح axe ليس امتثالًا شاملًا. التراجع عبر PR عكسي للواجهة أولًا ثم الخادم عند الحاجة، مع إبقاء جداول التشخيص الإضافية. لا نشر ولا تطبيق migration على DB المستخدم، ولا ادعاء خلو المشروع من كل عطل ممكن.
