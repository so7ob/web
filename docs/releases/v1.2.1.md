# v1.2.1 — استقلال المستودع وصيانة الاستعادة

إصدار تصحيحي بعد [v1.2.0](https://github.com/so7ob/web/releases/tag/v1.2.0). طلب المالك دمج develop إلى main وإنشاء الإصدار في [Issue #79](https://github.com/so7ob/web/issues/79). نشر الكود على GitHub منفصل عن نشر التطبيق وترحيل بيانات الإنتاج.

## التغييرات

- إزالة reference/ وأرشيف المصدر السابق وأدوات المقارنة المنتهية وCI الذي كان يشغّل checkout تاريخيًا بـBun؛ web وحده يكفي للتثبيت والبناء والفحص والتهيئة وتشغيل API والعامل والصيانة.
- اختبار استقلال فعلي للاستيرادات والتحميل الديناميكي والإعدادات وأوامر npm والقفل، مع منع Next/Prisma/Bun في المنتج وحفظ next-themes المستخدم.
- توحيد الأصول في apps/web/public، والتحقق من كل الصور وCSS والخطوط عبر HTTP من حزمة مستعادة تملك ملفاتها واعتمادياتها.
- حذف الشيفرة والحزم غير المستخدمة المثبتة؛ عقود API وأحجام CMS منقولة بايتًا ببايت إلى tests/fixtures، والترحيلات والصلاحيات والأدلة والحقوق محفوظة.
- إصلاح مساحة النقر لروابط التذييل إلى 24×24 CSS px على الأقل، دون تغيير النصوص أو URLs. فحص bounds فعلي وكيبورد وaxe باللغتين عند 375/1280، مع خط احتياطي أيضًا.

## الترقية من v1.2.0 والتوافق

Node 24.21.0، npm 10.8.2، MariaDB 10.11.18 باقية. لا migrations جديدة أو تغيير API أو أدوار أو جلسات أو بيانات. استخدم npm ci والقفل المرفق، ثم البناء وتشغيل API والعامل بإعداداتهما الخاصة. احتفظ بـDATA_DIR والأسرار والملفات وقاعدة المستخدم خارج شجرة الكود.

مصدر الأصول apps/web/public هو المسار التشغيلي وحزمة الاستعادة الآن؛ لا تنقل public الجذري من إصدار قديم. أدوات التقاط Website ومقارنته وجلب مصدره انتهى دورها؛ ليست أوامر صيانة معتمدة. تبقى data:transfer وdata:backup وdata:recovery-check وtest:restore والترحيلات الحالية ووظائف العامل والمصادقة والملفات والـwebhook وCMS.

من يبدأ بإصدار أقدم من v1.2.0 يراجع [ترقيته وترحيلاته](v1.2.0.md) أولًا. نشر هذا الإصدار لا يطبق migration على قاعدة موجودة ولا يغير بيانات الإنتاج.

## التحقق والحدود

CI في PR التحضير ثم PR develop إلى main هو مرجع SHA ونتائج الإصدار الفعلية، ويُراجع قبل نشر tag. فشل develop@5324f97 في [run 38165792437](https://github.com/so7ob/web/actions/runs/38165792437): 239 رحلة نجحت وmobile/en reset فشلت بقاعدة axe target-size في التذييل. أُصلح العنصر نفسه؛ لم تتغير القاعدة أو assertions ولم تُضف retries أو skips. سجل الفشل والصور والمقارنة في تقرير الإصدار.

الفحوص تستخدم بيانات اصطناعية وMariaDB معزولة؛ الاستعادة على المضيف نفسه، وليست دليل فقد مضيف أو وصول البريد إلى مستلم خارجي أو نشرًا. تنبيهات npm الأمنية القائمة محفوظة في أدلة التثبيت؛ لم تُجر ترقية حزم أو ادعاء audit ناجح ضمن هذا الإصدار.

## التراجع

التراجع عن الكود عبر PR وgit revert، ثم npm ci والبناء من القفل. لا تعيد كتابة tags المنشورة أو تاريخ Git. حفظ قاعدة البيانات والملفات والأسرار خارج الإصدار يمنع استبدالها عند تبديل الكود؛ لا تستعد نسخة بيانات قديمة فوق كتابات أحدث.

## English summary

v1.2.1 makes web independent of the retired source archive and historical CI checkout, removes proven unused code/dependencies, preserves fixed test contracts and current migrations, and verifies recovered assets and fonts from the release itself. Footer links now keep a minimum 24×24 CSS px pointer target with keyboard, Arabic/English, responsive and fallback-font coverage. There are no new database migrations or API/authorization changes. This GitHub release does not deploy the application or migrate production data.
